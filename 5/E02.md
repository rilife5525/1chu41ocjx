// 漫格 COMIC：粗墨線賽璐璐上色、對話框座艙、撕紙翼緣、網點紋理、速度線
import { type ShipDrawOpts, mirror, path, flame, drawGear, type Pt } from "./shipUtil";
import { hexA } from "./sprites";

const Y = "#ffe500", M = "#ff2f8e", C = "#19c6ff", K = "#111111";

export function drawComic(ctx: CanvasRenderingContext2D, o: ShipDrawOpts) {
  const t = o.t;
  drawGear(ctx, o, false);
  // 速度線
  ctx.save(); ctx.strokeStyle = hexA("#ffffff", 0.5); ctx.lineWidth = 1.5;
  for (let i = 0; i &lt; 6; i++) { const x = -30 + i * 12, l = 20 + ((i * 7 + Math.floor(t * 20)) % 5) * 6; ctx.beginPath(); ctx.moveTo(x, 34); ctx.lineTo(x, 34 + l * (0.5 + o.thrust)); ctx.stroke(); }
  ctx.restore();
  flame(ctx, 0, 30, 6, 14 + o.thrust * 14, t, "#ffffff", M);
  ctx.save();
  ctx.scale(1 - Math.abs(o.bank) * 0.14, 1);
  ctx.lineJoin = "round";
  // 撕紙翼
  for (const s of [-1, 1]) {
    ctx.save(); ctx.scale(s, 1);
    const wing: Pt[] = [[6, -8], [36, 10], [33, 14], [37, 18], [32, 22], [34, 26], [10, 20]];
    path(ctx, wing); ctx.fillStyle = Y; ctx.fill();
    ctx.save(); path(ctx, wing); ctx.clip();
    ctx.fillStyle = M; for (let x = 8; x &lt; 40; x += 5) for (let y = -8; y &lt; 28; y += 5) { const r = 0.6 + ((x + y) % 10) / 10 * 1.2; ctx.beginPath(); ctx.arc(x + ((y / 5) % 2) * 2.5, y, r, 0, Math.PI * 2); ctx.fill(); }
    ctx.restore();
    path(ctx, wing); ctx.strokeStyle = K; ctx.lineWidth = 2.5; ctx.stroke();
    if (o.tier >= 1) { path(ctx, [[34, 10], [44, 4], [38, 14]]); ctx.fillStyle = C; ctx.fill(); ctx.strokeStyle = K; ctx.lineWidth = 2; ctx.stroke(); }
    if (o.tier >= 2) { path(ctx, [[10, 20], [22, 30], [12, 30]]); ctx.fillStyle = M; ctx.fill(); ctx.strokeStyle = K; ctx.stroke(); }
    ctx.restore();
  }
  // 機身
  const body = mirror([[0, -42], [6, -28], [9, -4], [8, 18], [5, 30], [0, 28]]);
  path(ctx, body); ctx.fillStyle = "#ffffff"; ctx.fill();
  ctx.save(); path(ctx, body); ctx.clip(); ctx.fillStyle = Y; ctx.fillRect(-10, -10, 20, 40); ctx.fillStyle = M; ctx.fillRect(-10, 14, 20, 4); ctx.restore();
  path(ctx, body); ctx.strokeStyle = K; ctx.lineWidth = 2.8; ctx.stroke();
  // 對話框座艙
  ctx.fillStyle = C;
  ctx.beginPath(); ctx.ellipse(0, -20, 7, 9, 0, 0, Math.PI * 2); ctx.fill();
  ctx.beginPath(); ctx.moveTo(3, -12); ctx.lineTo(8, -4); ctx.lineTo(-1, -11); ctx.fill();
  ctx.strokeStyle = K; ctx.lineWidth = 2; ctx.beginPath(); ctx.ellipse(0, -20, 7, 9, 0, 0, Math.PI * 2); ctx.stroke();
  ctx.fillStyle = "#ffffff"; ctx.beginPath(); ctx.ellipse(-2.5, -23, 2, 3, -0.4, 0, Math.PI * 2); ctx.fill();
  // 機首「!」
  ctx.fillStyle = K; ctx.font = "900 10px Anton"; ctx.textAlign = "center"; ctx.fillText("!", 0, -32);
  ctx.restore();
  if (o.tier >= 3) {
    const s = 1 + Math.sin(t * 6) * 0.08;
    ctx.save(); ctx.translate(30, -36); ctx.scale(s, s); ctx.rotate(0.2);
    ctx.font = "900 14px 'Noto Sans TC'"; ctx.lineWidth = 3; ctx.strokeStyle = K; ctx.strokeText("ドン", 0, 0); ctx.fillStyle = Y; ctx.fillText("ドン", 0, 0);
    ctx.restore();
  }
  drawGear(ctx, o, true);
}

// 雙子 GEMINI：星芒機身、前掠星翼、雙尾翼；mode 0 粉／1 藍；合璧形態為四翼雙色
import { type ShipDrawOpts, mirror, fillPoly, lin, rad, flame, drawGear } from "./shipUtil";
import { glow, hexA } from "./sprites";

function star(ctx: CanvasRenderingContext2D, x: number, y: number, r: number, c: string, rot = 0) {
  ctx.save(); ctx.translate(x, y); ctx.rotate(rot);
  ctx.fillStyle = c; ctx.beginPath();
  for (let i = 0; i &lt; 8; i++) { const a = (i / 8) * Math.PI * 2 - Math.PI / 2, rr = i % 2 ? r * 0.35 : r; ctx.lineTo(Math.cos(a) * rr, Math.sin(a) * rr); }
  ctx.closePath(); ctx.fill(); ctx.restore();
}

function single(ctx: CanvasRenderingContext2D, o: ShipDrawOpts, C: string, C2: string) {
  const t = o.t, D = "#1a0a26";
  flame(ctx, 0, 28, 6, 18 + o.thrust * 18, t, "#ffffff", C);
  // 前掠星翼
  for (const s of [-1, 1]) {
    ctx.save(); ctx.scale(s, 1);
    fillPoly(ctx, [[5, 6], [30, -14], [36, -18], [32, -8], [14, 18], [6, 20]], lin(ctx, 5, -18, 36, 20, [[0, "#4a2060"], [1, D]]), C, 1.2);
    star(ctx, 34, -16, o.tier >= 1 ? 7 : 5, C2, t * 2 * s);
    // 雙尾翼
    fillPoly(ctx, [[4, 16], [12, 30], [8, 32], [3, 24]], hexA(C, 0.8));
    if (o.tier >= 2) fillPoly(ctx, [[10, 10], [24, 14], [20, 20]], hexA(C2, 0.8));
    ctx.restore();
  }
  const body = mirror([[0, -40], [4, -26], [7, -6], [6, 14], [4, 28], [0, 26]]);
  fillPoly(ctx, body, lin(ctx, 0, -40, 0, 28, [[0, "#ffffff"], [0.25, C], [0.7, "#3a1450"], [1, D]]), C2, 1);
  // 星核
  ctx.save(); ctx.globalCompositeOperation = "lighter"; ctx.drawImage(glow(C), -14, -14, 28, 28); ctx.restore();
  star(ctx, 0, 0, 7, "#ffffff", t * 1.5);
  ctx.fillStyle = rad(ctx, 0, -18, 6, [[0, "#ffffff"], [1, C]]);
  ctx.beginPath(); ctx.ellipse(0, -18, 3, 6, 0, 0, Math.PI * 2); ctx.fill();
}

export function drawGemini(ctx: CanvasRenderingContext2D, o: ShipDrawOpts) {
  const P = "#ff7ad9", B = "#5ad8ff";
  drawGear(ctx, o, false);
  ctx.save();
  ctx.scale(1 - Math.abs(o.bank) * 0.14, 1);
  if (o.tier >= 3 && o.form === 1) {
    // 合璧形態：雙色四翼、旋轉雙環
    const t = o.t;
    ctx.save(); ctx.globalCompositeOperation = "lighter";
    ctx.strokeStyle = hexA(P, 0.8); ctx.lineWidth = 2; ctx.beginPath(); ctx.ellipse(0, 0, 50, 20, t * 2, 0, Math.PI * 2); ctx.stroke();
    ctx.strokeStyle = hexA(B, 0.8); ctx.beginPath(); ctx.ellipse(0, 0, 50, 20, -t * 2, 0, Math.PI * 2); ctx.stroke();
    ctx.drawImage(glow("#ffffff"), -40, -40, 80, 80);
    ctx.restore();
    ctx.save(); ctx.scale(1.2, 1.2);
    ctx.save(); ctx.rotate(0.25); single(ctx, o, P, "#ffe0f6"); ctx.restore();
    ctx.save(); ctx.rotate(-0.25); ctx.globalAlpha = 0.85; single(ctx, o, B, "#e0f8ff"); ctx.restore();
    ctx.restore();
  } else {
    single(ctx, o, o.mode === 1 ? B : P, o.mode === 1 ? "#e0f8ff" : "#ffe0f6");
    if (o.tier >= 3) { ctx.save(); ctx.globalCompositeOperation = "lighter"; ctx.strokeStyle = hexA(o.mode === 1 ? B : P, 0.6); ctx.lineWidth = 1.5; ctx.beginPath(); ctx.arc(0, 0, 44, o.t, o.t + Math.PI); ctx.stroke(); ctx.restore(); }
  }
  ctx.restore();
