# 02 — 機體工作單

> 給**外部模型**：你要動哪一台，就看該台的「工作單」。每張工作單都寫明**落點檔案**、**安全等級**與**驗收方式**。  
> 給**我方**：§1 是 80 台總表（唯一資料來源），§4 是覆蓋錯位現況。
>
> 前置閱讀：`01-架構與鐵則.md`（尤其 §3 五條鐵則）。**沒看 01 就動手＝靜默弄壞覆蓋表。**

---

## 0. 這份怎麼用

1. 先在 §1 找到目標機體 → 看它的**家族**（決定你要改哪支 `drawGear`）與**覆蓋**欄（決定你的安全等級）。
2. 若該台在 §2／§3 有工作單 → 直接照著做。
3. 若沒有 → 用 `03-範本與提示詞.md` 的範本；**視覺語彙抄 §1.3 的那一列**，  
   顏色按 `01` §4.2 的明度階梯推導。
4. 改完跑 `01` §6 的驗收清單。

**「安全等級」定義：**

| 等級     | 意思              | 條件                                     |
| ------ | --------------- | -------------------------------------- |
| **L1** | 只換顏色字串，不動任何圖元數量 | 任何情況都安全                                |
| **L2** | 改／增／刪幾何圖元       | ✅ **Step 0 已完成 → 一律安全**（gear 圖元不佔覆蓋索引） |

> ✅ **Step 0 已於 2026-10-12 完成**（`01` §5）：`drawGear` 的圖元記 `GEAR_OP = -1`、不佔 `opCount`。  
> 所以下面各工作單寫的「⚠ 有覆蓋 → 需 Step 0」**已經全部解除**，直接做 L2 即可。

## 2. 七台「突兀／不搭」逐台工作單

> 這 7 台的問題**不是顏色，是幾何**（`01` §4.1）：家族的 `drawGear` 是通用零件，硬掛在輪廓完全不同的機體上。  
> 所以這 7 台要做的是 **L2 客製**，不是 L1 換色。
